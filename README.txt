راهنمای نصب روی اندروید
1) فایل ZIP را استخراج کنید.
2) برای نصب واقعی PWA باید فایل‌ها روی یک وب‌سرور HTTPS قرار بگیرند.
3) سپس آدرس index.html را در Chrome باز کنید.
4) منوی سه‌نقطه Chrome > Install app / نصب برنامه.

نکته: باز کردن مستقیم فایل index.html از حافظه گوشی معمولاً Service Worker و نصب PWA را فعال نمی‌کند.

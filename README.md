# دستیار باربرگ شهری — نسخه ۲.۲.۰

این نسخه داشبورد را به صفحه شروع برنامه تبدیل می‌کند و مدیریت ناوگان را در صفحه جداگانه قرار می‌دهد.

## پیش‌نیازها
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.3
- Gradle 8.9

## ساخت
GitHub Actions پس از push، pull request یا اجرای دستی، lint، تست واحد و `assembleDebug` را اجرا می‌کند و APK را به‌عنوان Artifact با نگهداری ۳۰ روز منتشر می‌کند.

در محیط دارای Gradle 8.9:
```bash
gradle clean :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## وضعیت فعلی
- داشبورد به‌عنوان صفحه شروع برنامه
- ورود جداگانه به مدیریت ناوگان
- ذخیره و بازیابی ناوگان‌ها با SharedPreferences
- افزودن، حذف و جلوگیری از نام خالی/تکراری/بیش از ۶۰ نویسه
- کد اولیه OTP و هش در پروژه موجود است، اما صدور باربرگ عملیاتی هنوز تکمیل نشده است.

## اتصال رسمی SIPAAD
فایل WSDL و راهنمای فنی ارائه‌شده شامل قرارداد متدهایی مانند `WS01_InsertBOL` است. کد فعلی برنامه هنوز این متد را پیاده‌سازی نکرده و نباید به‌عنوان نسخه عملیاتی ثبت باربرگ استفاده شود. پیش از فعال‌سازی باید ساختار درخواست، endpoint دقیق، احراز هویت، پاسخ‌های خطا و آزمون مجاز سرویس با قرارداد رسمی تطبیق داده شود.

## امنیت
- رمز یا کلید محرمانه را در مخزن قرار ندهید.
- رمز عبور در انتهای تلاش درخواست از حافظه موقت پاک می‌شود.
- استفاده عملیاتی فقط با مجوز رسمی و آزمون در محیط مجاز انجام شود.

## Gradle Wrapper
فایل wrapper در این بسته وجود ندارد؛ Workflow از Gradle 8.9 نصب‌شده در GitHub Actions استفاده می‌کند.

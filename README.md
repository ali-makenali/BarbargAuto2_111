# دستیار باربرگ شهری — نسخه ۲.۱

این مخزن شامل یک پوسته اولیه اندروید برای مدیریت محلی چند ناوگان، به‌همراه کد اولیه هش سرویس و دو متد OTP است.

## ساخت APK

ساخت خودکار از مسیر GitHub Actions و workflow با نام **Build Barbarg APK** انجام می‌شود. فایل خروجی `app-debug.apk` به‌صورت Artifact بارگذاری می‌شود.

تنظیمات ساخت این نسخه:
- JDK 17
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Android SDK Platform 35
- Kotlin Android Plugin 2.0.21

## وضعیت عملکرد

این نسخه هنوز یک سامانه کامل صدور باربرگ نیست. صفحه اصلی فعلی فقط امکان افزودن موقت نام ناوگان در حافظه برنامه را دارد. کد `UtcmsApi` شامل تلاش اولیه برای متدهای تولید و تأیید OTP است، اما اتصال زنده، احراز هویت عملیاتی، ثبت باربرگ، ارسال GPS و دریافت نتیجه قطعی سامانه در این نسخه تکمیل یا اعتبارسنجی نشده‌اند.

فعال‌سازی وب‌سرویس باید فقط با مجوزها، مشخصات فنی رسمی، دسترسی معتبر و آزمون در محیط مجاز انجام شود. هیچ رمز یا کلید محرمانه‌ای را در مخزن GitHub قرار ندهید.

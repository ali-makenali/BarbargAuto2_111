# دستیار باربرگ شهری — نسخه ۲.۱.۱

این پروژه یک پوسته اندرویدی برای مدیریت محلی ناوگان‌ها و نگهداری کد اولیه اتصال OTP و ثبت باربرگ در سامانه باربرگ شهری است.

## پیش‌نیازها
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.3
- Gradle 8.9

## ساخت
در GitHub Actions، workflow با نام **Build Barbarg APK** به‌صورت خودکار lint، تست واحد و `assembleDebug` را اجرا می‌کند و APK را به‌عنوان Artifact با نگهداری ۳۰ روز منتشر می‌کند.

در محیط دارای Gradle 8.9:
```bash
gradle clean :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## وضعیت فعلی
- مدیریت ناوگان‌ها با SharedPreferences و بازیابی پس از بستن برنامه
- افزودن، حذف و جلوگیری از نام خالی/تکراری/بیش از ۶۰ نویسه
- کد اولیه تولید و تأیید OTP در `UtcmsApi`
- اعتبارسنجی قالب کد ملی، موبایل و OTP
- اجرای درخواست شبکه در `Dispatchers.IO`

## محدودیت مهم اتصال SIPAAD
کد فعلی `UtcmsApi` قالب JSON را حفظ کرده است، اما این به معنی تأیید سازگاری آن با سرویس واقعی است. آدرس `.asmx` به‌تنهایی ثابت می‌کند که سرویس JSON می‌پذیرد یا قرارداد SOAP دارد.برای فعال‌سازی عملیاتی WSDL/مستندات رسمی SIPAAD، نام دقیق متدها، پارامترها، نوع داده‌ها، الگوریتم هش و نمونه پاسخ از مرجع مجاز دریافت و تطبیق داده شد. در این پروژه صدور باربرگ و ثبت قطعی است.

## امنیت
- رمز یا کلید محرمانه را در مخزن قرار ندهید.
- رمز عبور در انتهای تلاش درخواست از `CharArray` پاک می‌شود؛ برای هر درخواست باید حساب/رمز تازه ساخته شود.
- الگوریتم هش موجود صرفاً بر اساس پیاده‌سازی قبلی حفظ شده و برای تولید استفاده شود.
- TLS pinning عمداً بدون دریافت fingerprint معتبر و سازوکار چرخش گواهی تنظیم شده است.
- استفاده عملیاتی فقط با مجوز رسمی، مشخصات فنی معتبر و آزمون در محیط مجاز انجام شود

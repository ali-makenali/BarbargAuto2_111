# دستیار باربرگ شهری — نسخه ۲.۱.۱

این پروژه یک پوسته اندرویدی برای مدیریت محلی ناوگان‌ها و نگهداری کد اولیه اتصال OTP است.

## پیش‌نیازها
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.7.3
- Gradle 8.9

## ساخت
در GitHub Actions، workflow با نام **Build Barbarg APK** به‌صورت خودکار lint، تست واحد و `assembleDebug` را اجرا می‌کند و APK را به‌عنوان Artifact با نگهداری ۳۰ روز منتشر می‌کند.

در محیط دارای Gradle 8.9:
```bash
gradle clean :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## وضعیت فعلی
- مدیریت ناوگان‌ها با SharedPreferences و بازیابی پس از بستن برنامه
- افزودن، حذف و جلوگیری از نام خالی/تکراری/بیش از ۶۰ نویسه
- کد اولیه تولید و تأیید OTP در `UtcmsApi`
- اعتبارسنجی قالب کد ملی، موبایل و OTP
- اجرای درخواست شبکه در `Dispatchers.IO`

## محدودیت مهم اتصال SIPAAD
کد فعلی `UtcmsApi` قالب JSON را حفظ کرده است، اما این به معنی تأیید سازگاری آن با سرویس واقعی نیست. آدرس `.asmx` به‌تنهایی ثابت نمی‌کند که سرویس JSON می‌پذیرد یا قرارداد SOAP دارد. پیش از فعال‌سازی عملیاتی باید WSDL/مستندات رسمی SIPAAD، نام دقیق متدها، پارامترها، نوع داده‌ها، الگوریتم هش و نمونه پاسخ از مرجع مجاز دریافت و تطبیق داده شود. در این پروژه صدور باربرگ و ثبت نتیجه قطعی هنوز پیاده‌سازی نشده است.

## امنیت
- رمز یا کلید محرمانه را در مخزن قرار ندهید.
- رمز عبور در انتهای تلاش درخواست از `CharArray` پاک می‌شود؛ برای هر درخواست باید حساب/رمز تازه ساخته شود.
- الگوریتم هش موجود صرفاً بر اساس پیاده‌سازی قبلی حفظ شده و تا تأیید رسمی نباید برای تولید استفاده شود.
- TLS pinning عمداً بدون دریافت fingerprint معتبر و سازوکار چرخش گواهی تنظیم نشده است.
- استفاده عملیاتی فقط با مجوز رسمی، مشخصات فنی معتبر و آزمون در محیط مجاز انجام شود.

## Gradle Wrapper
فایل `gradle-wrapper.properties` تنظیم شده است، اما فایل باینری استاندارد `gradle-wrapper.jar` و اسکریپت‌های تولیدشده در این بسته قرار نگرفته‌اند؛ آن‌ها را با Gradle 8.9 در ریشه پروژه ایجاد و به مخزن اضافه کنید:
```bash
gradle wrapper --gradle-version 8.9
```
تا آن زمان Workflow از Gradle 8.9 نصب‌شده توسط GitHub Actions استفاده می‌کند.
